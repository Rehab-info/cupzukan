# カップ酒図鑑 by 一献

駅の売店や旅先で出会う、一合(180ml)のカップ酒の図鑑です。宮城を中心に、全国のカップ酒を味わい・燗向き・ラベルから紹介します。「一献」「蔵旅 by 一献」「さかづき帳 by 一献」と並ぶシリーズのサイトです。

※「ワンカップ」は大関株式会社の登録商標なので、サイト名や説明では一般名称の「カップ酒」を使っています。

## ファイル構成

```
index.html          トップ(宮城の一合・全国のカップ酒・楽しみ方)  ← tools/build.py が作る
cup/<id>.html       1本ごとのページ                              ← tools/build.py が作る
data/cups.json      カップ酒のデータ(ここを編集して追加)
tools/build.py      データからページを作り直すスクリプト
assets/style.css    デザイン(一献・蔵旅と同じ配色)
assets/app.js       全国のカップ酒の絞り込み
images/             写真を置く場所(いまは未使用)
.nojekyll           GitHub Pages の Jekyll 処理を無効化
```

## GitHub Pages で公開する

1. GitHub の Rehab-info アカウントで新しいリポジトリ `cupzukan` を作る
2. このフォルダの中身をすべてアップロード
3. Settings → Pages → Source を「GitHub Actions」にする
4. 数分後に `https://rehab-info.github.io/cupzukan/` で公開されます

リポジトリ名を変えるときは、`tools/build.py` の `SITE` も直してください。

## カップ酒を追加する

`data/cups.json` の `cups` に1件追加して `python3 tools/build.py` を実行します(GitHub に上げると公開のときにも自動で実行されます)。打ち間違いがあると、どこがおかしいかを表示して止まります。

```json
{
  "id": "hitakami",                 // 英数字とハイフン(ページの名前 cup/hitakami.html になる)
  "name": "日高見 純米 カップ",
  "short": "日高見",                // カップの絵のラベルに縦に書く短い名前(4文字くらいまで)
  "kana": "ひたかみ",               // 任意
  "brewery": "平孝酒造",
  "pref": "宮城",
  "city": "石巻市",                 // 任意
  "region": "宮城",                 // 宮城 / 東北 / 関東 / 新潟・北陸 / 東海 / 近畿 / 中国・四国 / 九州
  "spec": "純米",                   // 表示する種類(自由に書けます)
  "cls": "junmai",                  // 絞り込み用:junmai=純米 ginjo=吟醸 honjozo=本醸造 futsu=普通酒
  "type": "sou",                    // ラベルの色:kun=薫酒 sou=爽酒 jun=醇酒 juku=熟酒
  "alc": "15%", "rice": "山田錦", "polish": "60%",   // 任意。確認できたときだけ
  "sweet": 1.0,                     // -2(甘口)〜 +2(辛口)
  "body": 0.2,                      // -2(淡麗)〜 +2(濃醇)
  "temps": ["花冷え", "涼冷え", "常温", "ぬる燗"],   // 雪冷え 花冷え 涼冷え 常温 ぬる燗 上燗 熱燗
  "best": "涼冷え",                 // temps の中で一番のおすすめ
  "pairing": ["握り寿司", "サザエの刺身"],
  "label": "カップのデザインの説明",
  "oneliner": "カードに出る一言紹介",
  "note": "味わいの紹介文",
  "buyNote": "どこで買えるか",
  "trademark": "任意。商標の表示が必要なときだけ",
  "sources": [{"title": "情報のもとの名前", "url": "https://..."}]
}
```

※ JSON にはコメントを書けないので、実際に追加するときは `//` 以降を消してください。

## 手元で確認する

```
python3 tools/build.py
python3 -m http.server 8000
# → http://localhost:8000
```

## 注意

- 味わいや甘辛の位置は、公開されている試飲記事や販売店の紹介をもとにした目安です。自分で飲んだ感想に合わせて直してください。
- 情報のもとには数年前の記事も含まれます。デザインや取り扱いが変わっていることがあるので、店頭で見かけたら確かめて直していくと安心です。
- カップの絵は実物のラベルを写したものではなく、タイプごとの色で描いたイメージです。写真を使うときは、自分で撮ったものか許可を得たものにしてください。
- `assets/` の CSS・JS を直したら、`tools/build.py` の `VERSION` を1つ上げてください。
